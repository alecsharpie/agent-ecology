# How Crowds Make Up Their Minds

An interactive, Distill-style explainer of everything in this repo. Open `how-crowds-make-up-their-minds.html` in a browser.

It is assembled from parts: `style.css`, `body.html` (text and figure slots), `app.js` (simulations and charts) and `data.json` (exported from the lab with `cd lab && node --experimental-strip-types scripts/export-article-data.ts > ../article/data.json`). Rebuild with `sh build.sh`.
