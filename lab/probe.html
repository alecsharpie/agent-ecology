Agent probes

One naming-game agent, one scripted history, many samples. Instead of inferring habits from a noisy population, we ask directly: given this history, what do you play? Naming game →

How this works
  1. Each probe fixes the agent's memory to a clear situation, such as "won 5 times in a row playing X".
  2. X, Y and Z are placeholders. Each probe is run with them rotated through all 10 names, so no single name's popularity decides the result, and the list order is shuffled for every call.
  3. The table counts what the model played: X (its own name), Y (the partner's name, or the main one), Z (a second partner name), or another name entirely.
