Naming game

24 language-model agents, each with only a short memory of its own games. Will they agree on a name that nobody chose for them? A replication of Ashery, Aiello & Baronchelli (2025) with small models running in your browser.

How this works
  1. Each round, the 24 agents are paired at random. Both agents in a pair secretly pick one name from the same list of 10.
  2. Same name: both get +100. Different names: both lose 50. That's all they're told. Nobody says which name to pick.
  3. Memory: each agent sees only its own last 5 rounds (what it picked, what its partner picked, the points). It never sees other pairs or the population.
  4. Every agent is the same model, called once per round with its own memory. The list order is shuffled for every call, so "pick the first option" can't pass for a preference.
  5. The question: does one shared name emerge from these private, local interactions? Which name? And how few stubborn agents does it take to overturn it?
